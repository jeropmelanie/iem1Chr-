# IEM1Chr - Advanced Android Launcher
A customizable gesture-driven homescreen launcher with dynamic icon pack support and repository-based auto-updates.

## Features
- 🎯 **Gesture Controls** - Swipe, double-tap, long-press customization
- 🎨 **Icon Packs** - Load and switch icon packs dynamically
- 🔄 **Auto-Updates** - Scans repo for updates without resetting user settings
- ⚙️ **Personalization** - Full customization for rooted & unrooted devices
- 💾 **Settings Persistence** - User preferences survive updates

## Project Structure
```
app/
├── src/main/java/com/jeropmelanie/iem1chr/
│   ├── core/              # Core launcher components
│   ├── gestures/          # Gesture detection & handling
│   ├── icons/             # Icon pack management
│   ├── updates/           # Update checker & installer
│   └── ui/                # UI components
├── res/                   # Resources
└── build.gradle
```
